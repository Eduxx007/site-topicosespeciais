# NORD — Site-base da atividade

Projeto estático para a prática de:

VS Code → Git → GitHub → Render → alteração → novo commit → auto-deploy.

## Estrutura

- `index.html`
- `assets/css/style.css`
- `assets/js/main.js`
- `assets/images/cafe-nord.svg`
- `assets/images/favicon.svg`

Não há dependências, framework ou etapa de build.

## Para testar localmente

Abra `index.html` no navegador ou utilize uma extensão de servidor local.

## Sugestões de alterações durante a atividade

1. Alterar a headline principal.
2. Alterar o texto do CTA.
3. Acrescentar uma pequena informação no rodapé.
4. Fazer commit e push.
5. Conferir a atualização automática no Render.
